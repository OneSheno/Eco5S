Sobre o projeto
O Eco5S foi desenvolvido como parte de um Trabalho de Conclusão de Curso do ensino médio técnico em Administração. A proposta foi aproximar os estudantes dos princípios da metodologia 5S, relacionando organização e cuidado com o ambiente escolar a atividades de gamificação.

Este repositório preserva o site produzido para apresentar a proposta, explicar os cinco sensos e direcionar os participantes ao jogo Order Up!.
O que você encontra
Página	Conteúdo
Início	Apresentação do Eco5S e da proposta acadêmica
O que é?	Explicação dos cinco sensos e exemplos no cotidiano escolar
Prática	Apresentação do Order Up!, links externos para jogar e uma tabela estática de pontuações


Os cinco sensos
- Seiri: utilização.
- Seiton: ordenação.
- Seiso: limpeza.
- Seiketsu: padronização, higiene e saúde.
- Shitsuke: disciplina.
Tecnologias
O site utiliza HTML, CSS e JavaScript, além de recursos externos para ícones e efeitos visuais. Não exige instalação de dependências nem etapa de compilação.
Como visualizar
1. Baixe ou clone este repositório.
2. Abra o arquivo index.html em um navegador.
3. Navegue pelas páginas usando o menu do site.
Alguns recursos dependem de conexão com a internet, incluindo imagens externas, bibliotecas e os links do jogo.
Contexto e estado do projeto
Projeto acadêmico finalizado, sem manutenção ativa prevista. O código foi preservado como registro do trabalho e da experiência de aprendizado em desenvolvimento web.

O site apresenta uma proposta de gamificação; ele não implementa um sistema de contas, monitoramento automático ou ranking dinâmico. O jogo é acessado por links externos, e seu código não está neste repositório.
